TOPIC: Email Issues

ISSUE: Cannot send or receive emails
SOLUTION:
1. Check your internet connection.
2. Log out of Outlook and log back in.
3. Check if your mailbox is full — delete unnecessary emails or empty trash.
4. Check the mail server status at status.company.com
5. If using Outlook desktop, go to File > Account Settings and verify the server settings.
6. Try accessing email via webmail: mail.company.com
ESCALATION: If webmail also does not work, raise a P2 ticket immediately.

ISSUE: Outlook is slow or not responding
SOLUTION:
1. Close Outlook and reopen it.
2. Disable unnecessary Outlook add-ins: File > Options > Add-ins > Manage COM Add-ins.
3. Compact the Outlook data file: File > Account Settings > Data Files > Settings > Compact Now.
4. If the OST file is corrupted, delete it and let Outlook recreate it.
5. Check if your mailbox size exceeds 50GB — archive old emails.
ESCALATION: Raise a P3 ticket if performance issue persists.

ISSUE: Not receiving emails from external senders
SOLUTION:
1. Check your spam/junk folder first.
2. Check if the sender's domain is blocked in your organization's email filter.
3. Ask the sender to check their bounce-back message.
4. Verify your email address is correctly shared with the external sender.
5. Contact IT to whitelist the external domain if needed.
ESCALATION: Raise a P2 ticket with sender's email address for IT to investigate.

ISSUE: Email password expired or locked out
SOLUTION:
1. Go to password reset portal: password.company.com
2. Use your employee ID and registered mobile number to reset.
3. New password must be at least 12 characters with uppercase, lowercase, number, and symbol.
4. Password cannot be same as last 5 passwords.
ESCALATION: If portal does not work, call IT helpdesk: 1800-IT-HELP
